MISS THORNE'S SHRUBBERY SHOWDOWN — PREMIUM YEAR 4 PWA
========================================================

WHAT THIS PACKAGE IS
A flat, GitHub-Pages-ready Progressive Web App. Upload every file in this folder to the root of a repository and enable GitHub Pages. No build step, npm install, database or server is required.

CORE MODES
• Team Battle — choose 2, 3 or 4 teams:
  - Capybara Crew
  - Sea Turtle Squad
  - Beaver Builders
  - Red Panda Rangers
• Kings & Queens — whole-class castle mode.
• Random Turn Order — animated mascot “burrow shuffle” reveals the fair order.
• Shout-Out / Buzzer — teacher assigns the answering team; optional one-team steal after a wrong answer.

ANSWER MODES
• Classic — verbal answer = 1 full progression step. Reveal A–D for a half-step question.
• Multiple Choice — A–D shown from the start. Correct = 1 full step. A selected option must pass the “Lock In Final Answer” confirmation before marking.
• In Kings & Queens mode, a wrong answer never removes progress the class has already earned.

YEAR 4 CONTENT
The Maths topic structure follows the supplied White Rose-style Year 4 overview:
Autumn: Place Value; Addition & Subtraction; Area; Multiplication & Division A.
Spring: Multiplication & Division B; Length & Perimeter; Fractions; Decimals A.
Summer: Decimals B; Money; Time; Shape; Statistics; Position & Direction.
Also includes English, Science, History, Geography, Computing, Quick-Fire Verbal Reasoning and Quick-Fire Non-Verbal Reasoning.

CLASSROOM FEATURES
• Designed for teacher control on iPad or laptop and display on whiteboard/TV.
• Large touch targets and high-contrast question text.
• Optional 20/30/45 second quick-fire timer; time running out never auto-marks a pupil wrong.
• Undo last mark, skip question and pass-turn controls.
• Scores/game state persist on the device through accidental refreshes.
• Fullscreen control and sound toggle.
• Offline-capable after first hosted load through the service worker.

GITHUB PAGES
1. Create/open a GitHub repository.
2. Upload ALL files from this package to the repository root.
3. Commit the files.
4. Repository Settings → Pages → Deploy from branch.
5. Select the main branch and /(root), then Save.
6. Open the Pages URL after deployment.
7. On iPad/iPhone: Safari Share → Add to Home Screen. On supported desktop browsers: use Install App.

NOTE ON ARTWORK
The app uses individual standalone, premium rendered Miss Thorne pose PNGs and individual full-body mascot PNG files. It never crops characters out of a composite image at runtime. Each habitat, the castle, the burrow-draw stage and the app icon are also separately rendered assets in the same visual world.
